Detailed Description

Implementation of the determinant calculation command for the CLI calculator.

This module implements the "Determinant_N" command for the CLI calculator, allowing users to compute the determinant of a square matrix provided as a flat vector. It parses input tokens, checks matrix validity, performs the determinant calculation recursively, and prints the result to the CLI output stream.
