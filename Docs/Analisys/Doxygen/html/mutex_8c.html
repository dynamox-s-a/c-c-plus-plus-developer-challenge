Detailed Description

Simple mutex implementation for mutual exclusion.

This module provides a basic mutex (mutual exclusion) mechanism for synchronizing access to shared resources. It includes functions to initialize, lock, and unlock a mutex handler. The implementation uses a boolean flag and busy-waiting for demonstration or single-threaded use only.
