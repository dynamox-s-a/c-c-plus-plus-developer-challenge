Detailed Description

Implementation of the power (exponentiation) command for the CLI calculator.

This module implements the "Power_N" command for the CLI calculator, allowing users to raise the current ANS value to the power of one or more input values. It parses input tokens, converts them to double, performs the exponentiation, and prints the result to the CLI output stream.

Implements the "Power_N" CLI command.

Parses the input stream for double values, raises the current ANS to the power of each value, and prints the result to the CLI output. Supports multiple values separated by ',' or within brackets.
