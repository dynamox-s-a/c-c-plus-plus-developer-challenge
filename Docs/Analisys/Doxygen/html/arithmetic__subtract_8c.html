Detailed Description

Implementation of the subtraction command for the CLI calculator.

This module implements the "Subtract" command for the CLI calculator, allowing users to subtract one or more input values from the current ANS value. It parses input tokens, converts them to double, performs the subtraction, and prints the result to the CLI output stream.

Implements the "Subtract" CLI command.

Parses the input stream for double values, subtracts each value from the current ANS, and prints the result to the CLI output. Supports multiple values separated by ',' or within brackets.
