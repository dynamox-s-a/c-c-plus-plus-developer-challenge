Detailed Description

Implementation of the root (N-th root) command for the CLI calculator.

This module implements the "Root_N" command for the CLI calculator, allowing users to compute the N-th root of the current ANS value with one or more input values. It parses input tokens, converts them to double, performs the root calculation, and prints the result to the CLI output stream.

Implements the "Root_N" CLI command.

Parses the input stream for double values, computes the N-th root of the current ANS for each value, and prints the result to the CLI output. Supports multiple values separated by ',' or within brackets.
